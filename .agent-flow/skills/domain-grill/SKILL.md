# Domain Grill

Use during the full-feature domain-grill phase.

Rules:

- Ask one question at a time.
- Provide a recommended answer for every question.
- Walk each branch of the design tree until decisions are explicit.
- If a question can be answered from code or docs, inspect those sources instead of asking.
- Challenge fuzzy domain terms against CONTEXT.md and ADRs when present.
